# Client-Tracker

A starter template for a tool that tracks clients, contacts, and engagement status.

## Planned Features

- Client directory with contact details
- Status tracking (lead, active, past, lost)
- Notes and follow-up reminders
- Search and filtering

## Getting Started

This is a static web app starter — no build step required.

1. Open `index.html` in your browser, or serve the folder:

   ```bash
   # Python
   python -m http.server 8000

   # or Node
   npx serve .
   ```

2. Open http://localhost:8000 in your browser.
